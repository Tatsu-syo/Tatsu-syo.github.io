Meiryo UIも大っきらい!!

Meiryo UIも大っきらい!!はWindowsのシステムフォント設定を変更するツールです。2012年にWindows 8からシステムフォント設定がなくなったのを機に作成しました。

Windowsのシステムフォント設定はアイコン表示やMozilla Thunderbirdのメールリスト表示などWin32/WinFormsを使ったプログラムの多くで使われています。

このプログラムを使うことでWindows 8/10/11でシステムフォント設定を変更できます。

ダウンロード

Meiryo UIも大っきらい!!は GitHub からダウンロードできます。

言語ファイル

使い方

  1. 自分の言語の言語ファイルをダウンロードします。
  2. インストールしたフォルダーにZipファイルを展開します。

公式言語ファイル

公式言語ファイルはプログラムのアーカイブに同梱されています。

新しい言語ファイルができたらこちらで公開します。
